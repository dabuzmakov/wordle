# Wordle

Консольная игра в духе Wordle на C#.

Программа загадывает слово из пяти русских букв. У игрока есть шесть попыток, чтобы угадать его. После каждой попытки буквы получают цветовую оценку:

- 🟩 `Green` — буква стоит на правильной позиции;
- 🟨 `Yellow` — буква есть в загаданном слове, но стоит не на своём месте;
- ❌ `Red` — такой буквы в загаданном слове больше нет.

## Текущее состояние

Реализованы MR1 и MR2.

### MR1 — базовая модель игры

- словарь из 50 русских слов;
- проверка длины слов в словаре;
- выбор загаданного слова по `seed`;
- одинаковый `seed` даёт одинаковое слово;
- пустой словарь отклоняется;
- модель игровой сессии `GameSession`;
- ограничение количества попыток;
- состояния игры: `InProgress`, `Win`, `Lose`;
- история попыток;
- тесты обязательных требований MR1.

### MR2 — игровая логика и проверка попыток

- проверка введённого слова: длина, русские буквы и наличие в словаре;
- обработка ввода без учёта регистра;
- невалидная попытка отклоняется и не расходует попытку;
- вычисление результата каждой буквы (`Green`, `Yellow`, `Red`);
- корректная обработка повторяющихся букв;
- переход в `Win` при угадывании слова;
- переход в `Lose` после исчерпания попыток;
- завершённая игра не принимает новые попытки;
- тесты обязательных требований MR2: валидация ввода, раскраска букв и завершение партии.
