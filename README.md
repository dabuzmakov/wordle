# Wordle

Консольная игра в духе Wordle, написанная на C#.
Программа загадывает слово из пяти русских букв. У игрока есть шесть попыток, чтобы его угадать.
После каждой попытки каждая буква получает цветовую оценку:

- 🟩 `Green` — буква стоит на правильной позиции;
- 🟨 `Yellow` — буква есть в загаданном слове, но стоит в другом месте;
- ❌ `Red` — свободных вхождений этой буквы в загаданном слове больше нет.

## Правила игры

1. Программа загадывает слово из словаря.
2. Введите слово из пяти русских букв.
3. После каждой попытки игра покажет результат для каждой буквы.
4. Некорректный ввод не расходует попытку.
5. Угадайте слово за шесть попыток, чтобы победить.
6. После завершения партии можно вернуться в меню и начать новую игру.

## Воспроизводимый режим

Для отладки и проверки можно использовать фиксированный `DeterminedSeed` при создании экземпляра GameConfig
Одинаковые словарь и `seed` приводят к одинаковому загаданному слову.

## Реализованные возможности

### MR1 — модель игры

- словарь из 50 русских слов;
- проверка длины слов;
- выбор загаданного слова по `seed`;
- модель игровой сессии `GameSession`;
- ограничение количества попыток;
- статусы `InProgress`, `Win`, `Lose`;
- история попыток.

### MR2 — игровая логика

- валидация введённого слова;
- проверка длины, русских букв и наличия слова в словаре;
- обработка ввода без учёта регистра;
- вычисление результата каждой буквы;
- корректная обработка повторяющихся букв;
- переходы в состояния победы и поражения;
- запрет новых попыток после завершения игры.

### MR3 — консольный интерфейс

- консольное меню;
- запуск новой игры;
- выход из приложения;
- несколько партий подряд без перезапуска;
- отображение истории попыток;
- сообщения об ошибках ввода;
- воспроизводимый режим для проверки.
